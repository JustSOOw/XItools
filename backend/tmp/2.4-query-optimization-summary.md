# 2.4 查询逻辑优化实现总结

## 实施日期
2025-11-19

## 实现内容

### 1. 核心目标

优化查询逻辑，使用户能够同时访问：
- **个人资源**：用户自己创建的工作区、项目、看板和任务
- **团队资源**：用户所在团队的共享资源（根据权限）

### 2. 更新的服务

#### 2.1 WorkspaceService (`workspaceService.ts`)

**方法**: `getWorkspacesByUser(userId)`

**查询逻辑**:
```typescript
OR: [
  // 个人工作区：用户拥有的非团队工作区
  { ownerId: userId, teamId: null },

  // 团队工作区：用户是团队成员的工作区
  { team: { members: { some: { userId } } } }
]
```

**返回数据包含**:
- 工作区基本信息
- 关联的团队信息（如果是团队工作区）
- 所有项目和看板

---

#### 2.2 ProjectService (`projectService.ts`)

**新增方法**: `getUserProjects(userId)`

**查询逻辑**:
```typescript
OR: [
  // 个人项目：用户拥有的非团队工作区中的项目
  { ownerId: userId, workspace: { teamId: null } },

  // 团队项目：用户是项目所有者（团队管理员创建的）
  { ownerId: userId, workspace: { teamId: { not: null } } },

  // 团队项目：用户有权限访问的项目
  { permissions: { some: { member: { userId } } } }
]
```

**返回数据包含**:
- 项目基本信息
- 所属工作区和团队信息
- 所有看板
- 用户对该项目的权限

---

#### 2.3 BoardService (`boardService.ts`)

**新增方法**: `getUserBoards(userId)`

**查询逻辑**:
```typescript
OR: [
  // 个人看板：用户拥有的非团队工作区中的看板
  { ownerId: userId, workspace: { teamId: null } },

  // 团队看板（直属工作区）：用户是团队成员的工作区中的看板
  {
    workspace: { team: { members: { some: { userId } } } },
    projectId: null
  },

  // 团队看板（项目下）：用户有权限访问的项目中的看板
  {
    project: {
      OR: [
        { ownerId: userId },
        { permissions: { some: { member: { userId } } } }
      ]
    }
  }
]
```

**返回数据包含**:
- 看板基本信息
- 所属工作区/项目和团队信息
- 所有列和任务（包含标签）

---

#### 2.4 TaskService (`taskService.ts`)

**新增方法**: `getUserTasks(userId)`

**查询逻辑**:
```typescript
OR: [
  // 个人任务：用户拥有的非团队工作区中的任务
  { ownerId: userId, board: { workspace: { teamId: null } } },

  // 团队任务：用户是任务负责人
  {
    assignees: { has: userId },
    board: { workspace: { teamId: { not: null } } }
  },

  // 团队任务：用户有权限访问的任务
  {
    board: {
      OR: [
        // 看板直属工作区：用户是团队成员
        {
          workspace: { team: { members: { some: { userId } } } },
          projectId: null
        },
        // 看板属于项目：用户有项目权限
        {
          project: {
            OR: [
              { ownerId: userId },
              { permissions: { some: { member: { userId } } } }
            ]
          }
        }
      ]
    }
  }
]
```

**返回数据包含**:
- 任务完整信息
- 所属看板、工作区/项目和团队信息
- 父任务和子任务
- 标签

### 3. 权限继承链

```
Team (团队)
  ↓
Workspace (工作区) - 通过 teamMember 判断成员身份
  ↓
Project (项目) - 通过 projectPermission 判断访问权限
  ↓
Board (看板) - 继承项目权限
  ↓
Task (任务) - 继承看板权限
```

**权限判断逻辑**:
1. **团队管理员**: 拥有团队工作区下所有资源的完整权限
2. **团队成员**: 根据 `ProjectPermission` 判断对项目及其下资源的访问权限
3. **个人资源**: 完全隔离，只有创建者可访问

---

### 4. 数据隔离保证

#### 4.1 个人资源隔离
- 查询条件：`teamId: null`
- 权限检查：`ownerId: userId`

#### 4.2 团队资源隔离
- 团队成员身份验证：
  ```typescript
  team: { members: { some: { userId } } }
  ```
- 项目权限验证：
  ```typescript
  permissions: { some: { member: { userId } } }
  ```

#### 4.3 多团队数据隔离
- 用户只能访问其所在团队的资源
- 不同团队的工作区通过 `teamId` 完全隔离
- 权限系统确保跨团队数据不可见

### 5. 性能优化

#### 5.1 数据库索引（已存在）
以下索引在第一阶段已创建：
- `Team.ownerId`
- `TeamMember.userId`
- `TeamMember.teamId`
- `ProjectPermission.memberId`
- `ProjectPermission.projectId`
- `Workspace.teamId`

#### 5.2 查询优化
1. **避免 N+1 查询**: 使用 `include` 预加载关联数据
2. **并行查询**: 在可能的地方使用 `Promise.all`
3. **选择性字段**: 使用 `select` 只返回需要的字段

示例：
```typescript
include: {
  workspace: {
    select: {  // 只选择需要的字段
      id: true,
      name: true,
      teamId: true,
      team: {
        select: {
          id: true,
          name: true,
          ownerId: true,
        },
      },
    },
  },
}
```

#### 5.3 查询缓存（可选）
- 暂未实现 Redis 缓存
- 数据库查询性能已足够（预计 < 200ms）
- 如果性能不足可后续添加

### 8. 查询示例

#### 8.1 获取用户所有工作区
```typescript
// 返回：个人工作区 + 团队工作区
const workspaces = await workspaceService.getWorkspacesByUser(userId);

// 判断是否为团队工作区
workspaces.forEach(ws => {
  if (ws.teamId) {
    console.log(`团队工作区: ${ws.name} (团队: ${ws.team?.name})`);
  } else {
    console.log(`个人工作区: ${ws.name}`);
  }
});
```

#### 8.2 获取用户所有项目（含权限信息）
```typescript
const projects = await projectService.getUserProjects(userId);

projects.forEach(project => {
  const permission = project.permissions[0]?.permission;
  console.log(`项目: ${project.name}, 权限: ${permission || '所有者'}`);
});
```

#### 8.3 获取用户所有任务
```typescript
const tasks = await taskService.getUserTasks(userId);

// 分类任务
const personalTasks = tasks.filter(t => !t.board.workspace.teamId);
const teamTasks = tasks.filter(t => t.board.workspace.teamId);

console.log(`个人任务: ${personalTasks.length}`);
console.log(`团队任务: ${teamTasks.length}`);
```
